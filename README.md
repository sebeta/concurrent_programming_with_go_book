# Learn Concurrent Programming with Go — My Solutions

Hey! This repo is my attempt at solving the exercises from the book
**Learn Concurrent Programming with Go** by James Cutajar (first edition).

Each `chapterN` folder has my solutions for that chapter's exercises.

## A few things worth knowing

- These are my own attempts, so they're not necessarily the "best" or the
  only way to solve each exercise. Some may have rough edges.
- I left comments in several exercises explaining the parts that confused me
  the most, so I can come back later and understand them again.
- I did use AI in several cases. I used it to talk through ideas, check my
  reasoning and understand why things work, not just to get an answer. My goal
  was to really understand concurrency in Go.

If you're also working through the book, feel free to take a look.
